Why Firebrox

A real agent, not a chat wrapper

Firebrox plans, calls tools, inspects results, and answers — with every step streamed to the UI as it happens.

🔁

True agent loop

Multi-step reasoning with tool calls — up to 8 steps per turn by default, with live SSE streaming of every token and tool result.

🔌

Provider-agnostic

One unified interface over OpenAI, Anthropic, Gemini, Groq, Ollama, LM Studio, vLLM, or any OpenAI-compatible endpoint.

🧠

Zero-key demo brain

No API key? An offline heuristic brain routes your requests to the real tools, so the app works out of the box.

⚡

Sandboxed code execution

Run Python, JavaScript, or bash in an isolated subprocess with timeouts and output caps — safely.

🎨

Polished dark UI

Token streaming, collapsible tool cards with timing, live settings, and a responsive layout. No build step — pure vanilla JS.

🔒

Keys stay local

API keys live in a git-ignored local settings file or env vars. Nothing leaves your machine except model calls.

Quickstart

Running in under a minute

# clone & install $ git clone https://github.com/alrickdaley8-cpu/Firebrox $ cd Firebrox && npm install # start the server $ npm start 🔥 Firebrox running on http://localhost:3000 provider: demo | model: demo | tools: 9
# optional — plug in a real model (.env) FIREBROX_PROVIDER=openai FIREBROX_API_KEY=sk-... FIREBROX_MODEL=gpt-4o-mini
1

Install & run

npm install && npm start — the demo brain works instantly with no keys.

2

Add your model

Click ⚙ Settings in the app, pick a provider, paste a key — or point at local Ollama. Switch live, no restart.

3

Put it to work

“Search the web for X and summarize”, “run code”, “remember my favorite color” — watch the tool cards light up.

4

Make it yours

Add tools in server/tools/, providers in server/providers/ — clean, small modules.
